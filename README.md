# Problem Solving Lab

> A small gym for your programming brain.

I created this repository to practice solving problems. I can solve some problems with little help, but there are moments when I can't solve new problems I encounter.

This is where we all get to practice thinking, problem-solving, and comprehension of code.

## The rule

Solve the problem independently. For these beginner challenges, only use basic properties of the language, and **do not use any third party modules/libraries**. Avoid referring to the solution or copying the solution in the first attempt.

**Be aware of the use of tools**. From there on, it's perfectly fine to use documentation and AI to learn from the mistakes made and compare the approaches. Parameters of functions are encouraged when appropriate to the problem.

## About AI

I used AI to create the first eight puzzles while I was learning. Solved some puzzles on my own and got some AI feedback on them and fixed some of my code.

This repository is meant for learning how to solve a problem, rather than collecting answers.

## How to use this repo

1. Read the puzzles in [`puzzles/`](puzzles/README.md).
2. Try it out without seeing the solution
3. Test your program with the examples provided
4. After completing, look at other solutions in the folder [`solutions/`](solutions/README.md).
