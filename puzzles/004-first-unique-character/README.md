# Puzzle #004 — First Unique Character

**Type:** Solve  
**Difficulty:** Beginner  
**Skill:** Count characters

## Problem

Given a string, return the first character that appears exactly once. Return `None` if every character appears more than once.

## Rules

- Compare uppercase and lowercase as different characters.
- Do not use `count()`, `Counter`, or another ready-made frequency helper.
- Keep the original character order.

## Examples

Input: `"aabcddeeb"`  
Output: `"c"`

Input: `"swiss"`  
Output: `"w"`

Input: `"aabb"`  
Output: `None`

## Edge cases

An empty string returns `None`.
