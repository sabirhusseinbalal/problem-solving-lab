# Puzzle #003 — Longest Climb

**Type:** Solve  
**Difficulty:** Beginner  
**Skill:** Track a streak

## Problem

Return the length of the longest consecutive streak in which every number is strictly greater than the number before it. You cannot skip items.

## Rules

- The values must be next to each other.
- Each next number must be greater, not equal.
- An empty list returns `0`.

## Examples

Input: `[1, 2, 4, 3, 5, 6, 7, 2]`  
Output: `4`

Input: `[3, 5, 4, 6, 7]`  
Output: `3`

Input: `[5, 4, 3]`  
Output: `1`

## Edge cases

A one-item list returns `1`; an empty list returns `0`.
