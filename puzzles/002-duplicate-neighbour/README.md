# Puzzle #002 — Duplicate Neighbour

**Type:** Solve  
**Difficulty:** Beginner  
**Skill:** Compare neighbours

## Problem

Given a list of numbers, return the first number that appears twice next to itself. If no two neighbours are equal, return `None`.

## Rules

- Only adjacent numbers count.
- Return the first matching number.
- Do not use a ready-made duplicate finder.

## Examples

Input: `[2, 5, 3, 3, 7, 7, 7, 9]`  
Output: `3`

Input: `[1, 2, 3, 4]`  
Output: `None`

Input: `[8, 8, 2]`  
Output: `8`

## Edge cases

An empty list and a one-item list should return `None`.
