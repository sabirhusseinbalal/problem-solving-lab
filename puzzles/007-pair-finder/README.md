# Puzzle #007 — Pair Finder

**Type:** Solve  
**Difficulty:** Beginner  
**Skill:** Check pairs

## Problem

Given a list of numbers and a target, return the first pair of different list elements whose sum equals the target. Return the pair as a tuple. If no pair exists, return `None`.

## Rules

- The two values must come from different positions.
- The pair does not have to be adjacent.
- Do not use a set or dictionary for this beginner challenge.

## Examples

Input: `numbers = [7, 1, 5, 3, 6, 4]`, `target = 6`  
Output: `(1, 5)`

Input: `numbers = [2, 4, 7]`, `target = 9`  
Output: `(2, 7)`

Input: `numbers = [3, 4]`, `target = 6`  
Output: `None`

Input: `numbers = [4, 4]`, `target = 8`  
Output: `(4, 4)`
