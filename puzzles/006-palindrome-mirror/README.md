# Puzzle #006 — Palindrome Mirror

**Type:** Solve  
**Difficulty:** Beginner  
**Skill:** Compare both ends

## Problem

Write a function that returns `True` if a string reads the same forward and backward, otherwise return `False`.

## Rules

- For this puzzle, compare letters without worrying about case.
- Do not use `[::-1]` or `reversed()`.
- An empty string counts as a palindrome.

## Examples

Input: `"CIVIC"`  
Output: `True`

Input: `"python"`  
Output: `False`

Input: `"abba"`  
Output: `True`

## Edge cases

A one-character string returns `True`.
