# Puzzle #001 — Missing Number

**Type:** Solve  
**Difficulty:** Beginner  
**Skill:** Search

## Problem

Given a list containing numbers from 1 to 10, exactly one number is missing. Return the missing number.

## Rules

- Exactly one number from 1 through 10 is missing.
- Do not use `set()` or a set-difference trick.
- Use basic loops and conditions.

## Examples

Input: `[1, 2, 3, 4, 6, 7, 8, 9, 10]`  
Output: `5`

Input: `[1, 2, 4, 5, 6, 7, 8, 9, 10]`  
Output: `3`

## Edge case

The missing number can be at the beginning or end of the range.
