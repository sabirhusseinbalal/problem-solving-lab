# Puzzle #005 — Zero Shifter

**Type:** Solve  
**Difficulty:** Beginner  
**Skill:** Build a new list

## Problem

Return a new list with all zeros moved to the end. Keep the order of all non-zero numbers the same.

## Rules

- Do not sort the list.
- Do not change the original list.
- Do not use a ready-made partition helper.

## Examples

Input: `[0, 3, 0, 1, 4, 0, 5]`  
Output: `[3, 1, 4, 5, 0, 0, 0]`

Input: `[4, 0, 2, 0, 1]`  
Output: `[4, 2, 1, 0, 0]`

Input: `[1, 2, 3]`  
Output: `[1, 2, 3]`

## Edge cases

An empty list stays empty. A list made only of zeros stays a list of zeros.
