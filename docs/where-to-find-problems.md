# Where to find practice problems

Try to practise and learn with these sites. Do not copy their exercises and solutions to this repo as your own work.

- [W3Resource Python puzzles](https://www.w3resource.com/python-exercises/puzzles/) — short Python exercises with examples and solutions.
- [Exercism](https://exercism.org/) — practice exercises for many languages.
- [MDN Learn Web Development](https://developer.mozilla.org/en-US/docs/Learn_web_development) — HTML, CSS, JavaScript tests and challenges.
- [GitHub's contributing guide](https://docs.github.com/en/get-started/exploring-projects-on-github/contributing-to-a-project) — how forks and pull requests work.

## Example: “Length of Strings in List”

This exercise is published by W3Resource: [open the original exercise](https://w3resource.com/python-exercises/puzzles/python-programming-puzzles-14.php). It asks for a list of string lengths, for example `['cat', 'car', 'fear']` gives `[3, 3, 4]`.

You can solve it for your own practice. Before adding that exact exercise to this repository, check W3Resource's reuse terms. If you cannot confirm permission to copy/adapt it, don't submit its wording or examples as a new original puzzle.

If you have an idea for a new original challenge, write down your own challenge in puzzles/010-your-own-title/README.md after the maintainer has approved. Place the solution in your own file, `solutions/010-your-own-title/python/your-github-username.py`.
